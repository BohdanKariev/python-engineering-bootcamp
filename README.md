# Python Practice & Automation

My working repository for learning Python and building practical automation scripts.

I have a background in Systems Engineering & Automation (B.Sc.) and I'm currently working through *"Automate the Boring Stuff with Python"* to apply Python to data processing, log parsing, and test automation.

### Structure
* `chapter_XX/` — notes and exercises from the book.
* `mini_projects/` — small scripts solving practical tasks (parsers, validators, CLI tools).
* [`PROGRESS.md`](./PROGRESS.md) — personal tracker of what I've learned and what I'm currently working on.
